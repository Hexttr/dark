# 📖 Как правильно пользоваться Robin

## ❌ Частая ошибка

**Неправильно:** Вводить URL напрямую
```
https://tcell.tj/ru
https://example.com
www.site.com
```

## ✅ Правильное использование

**Правильно:** Вводить поисковые запросы на английском языке

### Примеры правильных запросов:

1. **Проверка утечек данных:**
   ```
   email password leak database 2024
   stolen credentials gmail accounts
   database dump leaked passwords
   ```

2. **Мониторинг компании:**
   ```
   company-name data breach ransomware
   domain example.com credentials leak
   company-name customer data for sale
   ```

3. **Исследование угроз:**
   ```
   ransomware payments victims 2024
   phishing campaigns banking fake login
   zero-day vulnerability exploit CVE-2024
   ```

4. **Поиск API ключей:**
   ```
   exposed API keys tokens github
   AWS access keys leaked S3 bucket
   OAuth tokens access tokens leaked
   ```

## 🔄 Что делать, если вы ввели URL?

Приложение автоматически преобразует URL в поисковый запрос!

**Пример:**
- Вы вводите: `https://tcell.tj/ru`
- Приложение преобразует в: `domain tcell.tj credentials leak data breach`

## 💡 Как это работает?

1. **Вы вводите ключевые слова** (не URL!)
2. **AI генерирует оптимизированные запросы** для поиска
3. **Приложение ищет в dark web** через поисковые системы
4. **Результаты фильтруются** с помощью AI
5. **Создается итоговый отчет**

## 🎯 Примеры использования

### Пример 1: Проверка утечек email

### Пример 2: Мониторинг домена
```

```

### Пример 3: Поиск информации о компании
```

```

### Пример 4: Исследование фишинга
```
Запрос: phishing campaigns 2024 fake banking website
```

## ⚠️ Важные советы

1. **Используйте английский язык** - запросы работают лучше
2. **Будьте конкретны** - чем точнее запрос, тем лучше результаты
3. **Используйте ключевые слова** - не полные предложения
4. **Комбинируйте термины** - например: `password leak database 2024`

## 🚫 Чего НЕ делать

- ❌ Не вводите URL напрямую (хотя приложение попытается преобразовать)
- ❌ Не используйте русский язык (результаты будут хуже)
- ❌ Не используйте слишком общие запросы (`hack`, `password`)
- ❌ Не используйте полные предложения (лучше ключевые слова)

## 📝 Шаблоны запросов

### Для проверки утечек:
```
[тип данных] leak [год] database
email password leak 2024 database
credentials leak database dump
```

### Для мониторинга компании:
```
[название компании] data breach ransomware
domain [домен] credentials leak
[компания] customer data for sale
```

### Для исследования угроз:
```
[тип угрозы] [год] [детали]
ransomware payments 2024 victims
phishing campaigns banking fake login
zero-day vulnerability exploit CVE-2024
```

---

**Помните:** Robin ищет информацию по ключевым словам в dark web, а не переходит по прямым ссылкам!
