# 🔍 Найденные проблемы

## ❌ Критические проблемы:

### 1. **Ahmia блокирует запросы через Tor**
- **Статус:** 403 Forbidden
- **Причина:** Сайт блокирует запросы через Tor прокси
- **Решение:** Использовать clearnet запросы без Tor для Ahmia, или использовать альтернативные поисковые системы

### 2. **.onion домены не резолвятся**
- **Ошибка:** `getaddrinfo failed`
- **Причина:** Python пытается резолвить .onion домены через обычный DNS вместо Tor
- **Решение:** Использовать правильную библиотеку для работы с SOCKS5 и .onion доменами

### 3. **Парсер не находит результаты**
- **Причина:** Структура HTML изменилась или сайт блокирует запросы
- **Решение:** Обновить парсер под новую структуру

## ✅ Что работает:

- Tor прокси доступен на порту 9150
- Ollama работает, модель загружена
- Базовое соединение через Tor работает (check.torproject.org)

## 🔧 Решения:

1. **Для Ahmia:** Использовать запросы без Tor (clearnet)
2. **Для .onion сайтов:** Исправить резолвинг доменов
3. **Добавить альтернативные поисковые системы:** Которые работают через Tor
