# 🔍 Диагностика ошибок в браузере

## Как проверить ошибки

1. **Откройте браузер** и перейдите на http://localhost:8501
2. **Нажмите F12** (или правый клик → Inspect)
3. **Перейдите на вкладку Console** - там будут ошибки JavaScript
4. **Перейдите на вкладку Network** - проверьте, какие запросы не загружаются

## Возможные проблемы

### 1. Ошибка подключения
**Симптом:** "Unable to connect" или "Connection refused"
**Решение:** 
- Проверьте, что сервер запущен: `netstat -ano | findstr :8501`
- Перезапустите: `python -m streamlit run ui.py --server.port 8501`

### 2. Ошибка импорта модулей
**Симптом:** В консоли Python видны ошибки импорта
**Решение:** 
- Проверьте зависимости: `pip install -r requirements.txt`
- Проверьте импорты: `python test_ui.py`

### 3. Ошибка кодировки
**Симптом:** Кракозябры в интерфейсе
**Решение:** Уже исправлено в коде

### 4. Ошибка Streamlit
**Симптом:** Белый экран или ошибка в консоли браузера
**Решение:**
- Попробуйте упрощенную версию: `streamlit run ui_simple.py`
- Проверьте логи: смотрите вывод в терминале где запущен Streamlit

## Тестирование

Запустите упрощенную версию для проверки:
```bash
streamlit run ui_simple.py --server.port 8502
```

Если упрощенная версия работает, значит проблема в основном UI.
Если не работает - проблема в Streamlit или зависимостях.

## Что проверить

1. ✅ Python версия: `python --version` (должно быть 3.10+)
2. ✅ Зависимости: `pip list | findstr streamlit`
3. ✅ Порт свободен: `netstat -ano | findstr :8501`
4. ✅ Импорты работают: `python -c "import ui; print('OK')"`
