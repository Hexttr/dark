# 🔍 Анализ поиска tcell.tj - Что находит приложение

## 📊 Текущая ситуация:

### Что приложение делает:

1. **Поиск через Ahmia:**
   - Ищет .onion сайты по ключевым словам (например: "tcell.tj data breach")
   - Находит ссылки на .onion ресурсы
   - Извлекает snippet (краткое описание)

2. **Фильтрация через LLM:**
   - Анализирует найденные результаты
   - Оценивает релевантность
   - Отбирает наиболее подходящие

3. **Скрапинг контента:**
   - Скачивает содержимое найденных .onion страниц
   - Извлекает текст (до 5000 символов)
   - Сохраняет для анализа

4. **Генерация отчета:**
   - Анализирует скрапленный контент
   - Ищет упоминания домена в тексте
   - Формирует итоговый отчет

## ⚠️ Важное понимание:

### Приложение НЕ ищет напрямую упоминания домена в dark web

Вместо этого:
- ✅ Находит .onion сайты, которые могут содержать информацию
- ✅ Скрапит их содержимое
- ✅ Анализирует текст на наличие упоминаний

### Что это означает для tcell.tj:

Если приложение нашло результаты, это может быть:

1. **.onion сайты с упоминаниями tcell.tj:**
   - Торговые площадки с данными
   - Форумы с обсуждениями
   - Блоги с информацией об утечках
   - Базы данных с утечками

2. **НЕ гарантирует наличие упоминаний:**
   - Может быть просто релевантные .onion сайты
   - Может быть общая информация о телеком-компаниях
   - Может быть ложные срабатывания

## 🔍 Как проверить результаты:

### В отчете должно быть:

1. **Найденные .onion ссылки** - какие сайты найдены
2. **Snippet** - краткое описание из Ahmia
3. **Скрапленный контент** - текст со страниц
4. **Анализ LLM** - что найдено про tcell.tj

### Что искать:

- Упоминания "tcell.tj" в тексте
- Упоминания "tcell" в контексте утечек
- Ссылки на домен
- Данные клиентов или учетных записей
