# 🔒 Улучшенная генерация запросов для кибербезопасности

## ✅ Что улучшено:

### 1. **Автоматическое определение доменов** ✅
- Приложение теперь автоматически определяет, когда введен домен (например: `tcell.tj`)
- Автоматически генерирует запросы, сфокусированные на кибербезопасности

### 2. **Специализированные запросы для кибербезопасности** ✅
Приложение теперь генерирует запросы для поиска:

#### **Утечки данных:**
- Database dumps, credential leaks, data breaches
- Stolen credentials, passwords, customer data
- Compromised accounts, email leaks

#### **Уязвимости и эксплойты:**
- Security vulnerabilities, CVEs, exploits
- Zero-day vulnerabilities, security flaws
- Attack vectors, exploitation discussions

#### **Обсуждения атак:**
- Attack discussions, hacking forums mentions
- Ransomware attacks, DDoS discussions
- Social engineering campaigns, phishing

#### **Скомпрометированные данные:**
- Sold/stolen data, database sales
- Account credentials for sale
- Personal information leaks

#### **Инциденты безопасности:**
- Security incidents, breaches reports
- Compromised infrastructure discussions
- Security research findings

## 🔧 Как это работает:

1. **Определение типа запроса:**
   - Если введен домен (например: `tcell.tj`) → специальный режим для кибербезопасности
   - Если введен URL → автоматически извлекается домен и преобразуется в запрос
   - Если обычный запрос → добавляется контекст кибербезопасности

2. **Генерация через LLM:**
   - Используется улучшенный промпт, сфокусированный на кибербезопасности
   - LLM генерирует 12-15 специализированных запросов

3. **Fallback механизм:**
   - Если LLM не отвечает, используются предопределенные запросы
   - Гарантирует, что поиск всегда выполняется

## 💡 Преимущества:

1. **Автоматическое преобразование доменов** - не нужно вручную формулировать запросы
2. **Фокус на кибербезопасности** - все запросы направлены на поиск угроз
3. **Широкое покрытие** - ищет утечки, уязвимости, атаки, обсуждения
4. **Надежность** - есть fallback механизм, если LLM не работает
