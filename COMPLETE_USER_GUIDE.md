# 📖 Полное руководство пользователя: Robin - AI-Powered Dark Web OSINT Tool

## 🎯 Что это за приложение?

**Robin** — это инструмент для OSINT (Open Source Intelligence) расследований в dark web. Приложение использует искусственный интеллект (Ollama) для автоматизации поиска информации о безопасности, утечках данных и угрозах.

### Основные возможности:
- 🔍 Автоматический поиск в dark web через Tor
- 🤖 Генерация оптимизированных запросов через AI
- 📊 Анализ найденных результатов через AI
- 🕷️ Скрапинг содержимого найденных страниц
- 📝 Автоматическая генерация отчетов

---

## 🏗️ Как работает приложение?

### Процесс работы (пошагово):

```
1. ПОЛЬЗОВАТЕЛЬ ВВОДИТ ЗАПРОС
   ↓
2. ПРОВЕРКА СОЕДИНЕНИЙ
   - Проверка Tor (порт 9150)
   - Проверка Ollama (порт 11434)
   ↓
3. ГЕНЕРАЦИЯ ПОИСКОВЫХ ЗАПРОСОВ (через AI)
   - Анализ исходного запроса
   - Генерация 10-15 оптимизированных запросов
   - Фокус на кибербезопасности (утечки, уязвимости, атаки)
   ↓
4. ПОИСК В DARK WEB
   - Поиск в Ahmia (clearnet, без Tor)
   - Поиск в DuckDuckGo (clearnet, без Tor)
   - Поиск в Startpage (clearnet, без Tor)
   - Поиск в Onionland (clearnet, без Tor)
   - Находит ссылки на .onion сайты и другие ресурсы
   ↓
5. ФИЛЬТРАЦИЯ РЕЗУЛЬТАТОВ (через AI)
   - Анализ найденных результатов
   - Отбор релевантных результатов
   - Оценка релевантности (0.0-1.0)
   ↓
6. СКРАПИНГ КОНТЕНТА
   - Открытие найденных .onion страниц через Tor
   - Извлечение текста со страниц (до 10000 символов)
   - Сохранение содержимого для анализа
   ↓
7. АНАЛИЗ СКРАПЛЕННОГО КОНТЕНТА (через AI)
   - Поиск упоминаний домена/компании в тексте
   - Анализ информации о безопасности
   - Выявление угроз и утечек данных
   ↓
8. ГЕНЕРАЦИЯ ОТЧЕТА (через AI)
   - Создание структурированного отчета
   - Анализ найденной информации
   - Рекомендации по безопасности
   ↓
9. ВЫВОД РЕЗУЛЬТАТА
   - Показ отчета в интерфейсе
   - Сохранение отчета (опционально)
```

### Компоненты приложения:

#### 1. **config.py** - Конфигурация
- Настройки Tor (прокси, порты)
- Настройки Ollama (URL, модель)
- Список поисковых систем
- Параметры скрапинга

#### 2. **llm.py** - Работа с AI (Ollama)
- Генерация поисковых запросов
- Фильтрация результатов
- Анализ скрапленного контента
- Генерация отчетов

#### 3. **search.py** - Поиск в dark web
- Поиск через Tor
- Парсинг результатов поисковых систем
- Обработка .onion сайтов

#### 4. **scrape.py** - Скрапинг контента
- Извлечение текста со страниц
- Многопоточная обработка
- Специальная обработка .onion сайтов

#### 5. **ui.py** - Веб-интерфейс
- Streamlit веб-интерфейс
- Форма ввода запросов
- Отображение результатов
- Прогресс-бар

#### 6. **main.py** - CLI интерфейс
- Командная строка
- Параметры запуска
- Сохранение отчетов

## 🚀 Как правильно пользоваться приложением?

### Требования перед запуском:

#### 1. **Tor Browser** ✅
- Скачайте и установите Tor Browser
- Запустите Tor Browser (должен работать в фоне)
- Проверьте, что Tor работает на порту **9150**

#### 2. **Ollama** ✅
- Установите Ollama: https://ollama.ai/
- Загрузите модель: `ollama pull llama3.1:8b`
- Проверьте, что Ollama работает на порту **11434**

#### 3. **Python зависимости** ✅
```bash
pip install -r requirements.txt
```

### Запуск приложения:

#### Вариант 1: Веб-интерфейс (рекомендуется)

```bash
python run_ui.py
```

Или напрямую:
```bash
streamlit run ui.py --server.port 8501 --server.address 127.0.0.1
```

Откройте в браузере: **http://127.0.0.1:8501**

#### Вариант 2: CLI (командная строка)

```bash
python main.py cli --query "ваш запрос" --model llama3.1 --threads 10
```

## 🎯 Пошаговая инструкция использования:

### Шаг 1: Подготовка

1. **Запустите Tor Browser**
   - Откройте Tor Browser
   - Дождитесь подключения к сети Tor
   - Оставьте браузер открытым

2. **Запустите Ollama**
   - Убедитесь, что Ollama работает
   - Проверьте модель: `ollama list`
   - Если нет модели: `ollama pull llama3.1:8b`

3. **Запустите приложение**
   ```bash
   python run_ui.py
   ```

### Шаг 2: Ввод запроса

1. **Откройте веб-интерфейс**
   - Перейдите на http://127.0.0.1:8501

2. **Введите запрос**
   - Домен: `tcell.tj`
   - Или поисковый запрос: `password leak database 2024`

3. **Выберите параметры**
   - Модель: `llama3.1:8b` (по умолчанию)
   - Потоки: `10-12` (рекомендуется)

4. **Нажмите "Запустить расследование"**

### Шаг 3: Ожидание результатов

Процесс занимает **1-5 минут**:

1. **Проверка соединений** (10%)
   - Проверка Tor
   - Проверка Ollama

2. **Генерация запросов** (20%)
   - AI генерирует 10-15 запросов
   - Показывает список запросов

3. **Поиск в Dark Web** (40%)
   - Поиск в поисковых системах
   - Находит ссылки на .onion сайты

4. **Фильтрация результатов** (60%)
   - AI анализирует результаты
   - Отбирает релевантные

5. **Скрапинг контента** (80%)
   - Открывает найденные страницы
   - Извлекает текст со страниц

6. **Генерация отчета** (90%)
   - AI анализирует скрапленный контент
   - Создает структурированный отчет

7. **Готово!** (100%)
   - Показывает отчет
   - Можно сохранить отчет

### Шаг 4: Анализ результатов

#### Что смотреть в отчете:

1. **Executive Summary**
   - Краткое резюме найденной информации
   - Основные выводы

2. **Key Findings**
   - Детальная информация о находках
   - Упоминания домена/компании

3. **Domain Mentions Analysis**
   - Анализ упоминаний домена в скрапленном контенте
   - Где именно упоминается домен

4. **Threat Assessment**
   - Оценка угроз
   - Уровень риска (low/medium/high)

5. **Recommendations**
   - Рекомендации по безопасности
   - Что делать дальше

6. **Sources**
   - Список источников
   - Ссылки на найденные страницы

## ⚙️ Настройки и параметры:

### Параметры запуска:

#### Модель (`--model`):
- `llama3.1:8b` (по умолчанию) - быстрая, хорошее качество
- `llama3.1:70b` - медленнее, но лучше качество
- Другие модели Ollama

#### Потоки (`--threads`):
- `5-8` - для быстрого теста
- `10-12` - рекомендуется (баланс скорости и качества)
- `15-20` - для глубокого поиска (медленнее)

### Конфигурация (config.py):

#### Tor настройки:
```python
TOR_PROXY = "socks5://127.0.0.1:9150"  # Tor Browser
TOR_TIMEOUT = 60  # Таймаут запросов
```

#### Ollama настройки:
```python
OLLAMA_BASE_URL = "http://127.0.0.1:11434"
OLLAMA_DEFAULT_MODEL = "llama3.1"
```

#### Поисковые системы:
- Ahmia (clearnet, без Tor)
- DuckDuckGo (clearnet, без Tor)
- Startpage (clearnet, без Tor)
- Onionland (clearnet, без Tor)

## 🔧 Решение проблем:

### Проблема 1: Tor не работает

**Симптомы:**
- Ошибка "Tor не доступен"
- Таймауты при поиске

**Решение:**
1. Убедитесь, что Tor Browser запущен
2. Проверьте порт: должен быть **9150** (Tor Browser)
3. Попробуйте перезапустить Tor Browser

### Проблема 2: Ollama не работает

**Симптомы:**
- Ошибка "Ollama не доступен"
- Таймауты при генерации запросов

**Решение:**
1. Убедитесь, что Ollama запущен
2. Проверьте модель: `ollama list`
3. Загрузите модель: `ollama pull llama3.1:8b`
4. Проверьте порт: должен быть **11434**

### Проблема 3: Нет результатов

**Симптомы:**
- Поиск завершается, но результатов нет
- "Результаты не найдены"

**Решение:**
1. Попробуйте другой запрос (более конкретный)
2. Используйте английский язык
3. Добавьте больше ключевых слов
4. Проверьте интернет-соединение

### Проблема 4: Долго выполняется

**Симптомы:**
- Поиск занимает более 5 минут
- Зависает на каком-то этапе

**Решение:**
1. Уменьшите количество потоков (5-8)
2. Используйте более простой запрос
3. Проверьте скорость интернета
4. Проверьте, что Tor и Ollama работают нормально

## 📊 Что происходит внутри приложения?

### Технические детали:

#### 1. **Генерация запросов:**
- AI анализирует исходный запрос
- Генерирует 10-15 оптимизированных запросов
- Фокус на кибербезопасности (утечки, уязвимости, атаки)
- Если запрос - домен, автоматически добавляется контекст безопасности

#### 2. **Поиск:**
- Запросы отправляются в поисковые системы
- Clearnet системы (Ahmia, DuckDuckGo) работают без Tor
- Результаты парсятся и извлекаются ссылки
- Находятся ссылки на .onion сайты и другие ресурсы

#### 3. **Фильтрация:**
- AI анализирует найденные результаты
- Оценивает релевантность (0.0-1.0)
- Отбирает наиболее релевантные результаты
- Проверяет соответствие домена/компании

#### 4. **Скрапинг:**
- Открывает найденные страницы через Tor
- Извлекает HTML код страницы
- Парсит HTML и извлекает текст
- Сохраняет до 10000 символов на страницу
- Для .onion сайтов используется удвоенный таймаут (30 секунд)

#### 5. **Анализ:**
- AI анализирует скрапленный контент
- Ищет упоминания домена/компании в тексте
- Анализирует информацию о безопасности
- Выявляет угрозы и утечки данных

#### 6. **Генерация отчета:**
- AI создает структурированный отчет
- Включает Executive Summary, Key Findings, Threat Assessment
- Предоставляет рекомендации по безопасности
- Список источников с ссылками

## ⚠️ Важные замечания:

### 1. **Легальность:**
- Приложение предназначено для легитимных OSINT расследований
- Используйте только для законных целей
- Не используйте для незаконной деятельности

### 2. **Безопасность:**
- Всегда используйте Tor для анонимности
- Не вводите личные данные в запросы
- Будьте осторожны при открытии найденных ссылок

### 3. **Точность:**
- Результаты могут быть неточными
- Проверяйте информацию из разных источников
- Не полагайтесь только на результаты приложения

### 4. **Производительность:**
- Поиск может занимать 1-5 минут
- Некоторые .onion сайты могут быть недоступны
- Не все страницы можно скрапить
