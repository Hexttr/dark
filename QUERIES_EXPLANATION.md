# 🔍 Почему теперь 10-15 запросов вместо 6?

## ❓ Вопрос: Почему только 6 оптимизированных запросов?

**Ответ:** Раньше было 3-5 запросов, теперь увеличено до **10-15 запросов**!

## ✅ Что изменилось:

### До изменений:
- Генерировалось: **3-5 запросов**
- Промпт: "Generate 3-5 optimized search queries"

### После изменений:
- Генерируется: **10-15 запросов** ✅
- Промпт: "Generate 10-15 optimized search queries"
- Добавлено требование разнообразия запросов

## 🎯 Почему 10-15 запросов лучше?

### Преимущества большего количества запросов:

1. **Больше покрытие:**
   - Разные формулировки одной темы
   - Разные ключевые слова
   - Разные синонимы

2. **Больше результатов:**
   - Каждый запрос может найти уникальные результаты
   - Разные поисковые системы могут лучше реагировать на разные формулировки

3. **Лучшая фильтрация:**
   - Больше данных для анализа
   - AI может лучше определить релевантность

4. **Разнообразие:**
   - Запросы с разными стратегиями поиска
   - Разные комбинации ключевых слов

## 📊 Пример для tcell.tj:

### С 3-5 запросами (старый вариант):
```

2. tcell.tj credentials leak
3. tcell.tj database leak
```

### С 10-15 запросами (новый вариант):
```
1. tcell.tj data breach credentials leak
2. tcell.tj database leak customer data
3. domain tcell.tj credentials stolen
4. tcell.tj user accounts password leak
5. tcell telecommunications data breach
6. tcell tajikistan data breach
7. tcell.tj security incident customer information
8. tcell database dump leaked passwords
9. tcell.tj ransomware attack data
10. tcell telecommunications company breach 2024
11. tcell.tj user credentials for sale
12. tcell customer information leak dark web
13. tcell.tj compromised accounts database
14. tcell telecommunications security breach
15. tcell.tj leaked user data credentials
```

## ⚙️ Как это работает:

1. **Вы вводите запрос:** `tcell.tj data breach`
2. **Ollama генерирует 10-15 вариантов:**
   - Разные формулировки
   - Разные ключевые слова
   - Разные комбинации
3. **Приложение ищет по каждому запросу:**
   - Во всех 6 поисковых системах
   - Через Tor
4. **Результаты объединяются и фильтруются:**
   - Удаляются дубликаты
   - AI анализирует релевантность
   - Создается итоговый отчет

## 💡 Можно ли изменить количество?

Да, можно настроить в `llm_utils.py`:

```python
# Текущая настройка:
Generate 10-15 optimized search queries that:

# Можно изменить на:
Generate 5-10 optimized search queries that:  # Меньше запросов
Generate 15-20 optimized search queries that:   # Больше запросов
```

## ⚠️ Важно понимать:

- **Больше запросов = больше времени поиска**
- **Больше запросов = больше результатов (обычно)**
- **10-15 запросов** - оптимальный баланс для большинства задач

## 🎯 Рекомендации:

### Для простых запросов:
- Можно использовать 5-10 запросов
- Быстрее выполнение

### Для сложных расследований:
- Используйте 10-15 запросов (текущая настройка)
- Максимальное покрытие

### Для очень сложных случаев:
- Можно увеличить до 15-20 запросов
- Но это займет больше времени

---

**Итог:** Теперь приложение генерирует **10-15 оптимизированных запросов** вместо 3-5, что значительно увеличивает шансы найти нужную информацию! ✅
