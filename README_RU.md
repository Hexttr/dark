## 💡 Быстрые примеры

### Проверка утечек email
```bash
robin cli --model gpt-4.1 --query "email password leak your-email@example.com" --threads 10
```

### Мониторинг компании
```bash
robin cli --model claude-3-5-sonnet-latest --query "company-name data breach" --threads 12 --output report.txt
```

### Быстрый поиск
```bash
robin cli --model gemini-2.5-flash --query "phishing campaigns 2024" --threads 8
```

## 📋 Что такое Robin?

**Robin** - это AI-инструмент для OSINT-расследований в dark web, который:
- 🔍 Ищет информацию в dark web через Tor
- 🤖 Использует AI для фильтрации и анализа результатов
- 📊 Создает готовые отчеты для расследований
- 🛡️ Помогает защитить ваши данные и инфраструктуру
