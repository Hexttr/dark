# 🔍 Зачем нужен Tor, если поисковые системы работают без него?

## ❓ Вопрос:

В отчете указано, что поисковые системы (Ahmia, DuckDuckGo, Startpage, Onionland) работают **без Tor** (clearnet), но при этом приложение использует Tor. Зачем?

## ✅ Ответ:

### Tor используется НЕ для поиска, а для доступа к найденным .onion сайтам!

## 🔄 Как это работает:

### Этап 1: ПОИСК (БЕЗ Tor) ✅

**Поисковые системы:**
- Ahmia (clearnet) - работает БЕЗ Tor
- DuckDuckGo (clearnet) - работает БЕЗ Tor  
- Startpage (clearnet) - работает БЕЗ Tor
- Onionland (clearnet) - работает БЕЗ Tor

**Почему без Tor?**
- Эти сайты доступны в обычном интернете
- Они блокируют запросы через Tor (403 Forbidden)
- Работают быстрее без Tor
- Не требуют анонимности для доступа

**Результат поиска:**
```
Найдено: http://example.onion/page1
Найдено: http://another.onion/breach
Найдено: https://clearnet-site.com/data
```

### Этап 2: СКРАПИНГ (С Tor) ✅

**Что скрапится:**
- Найденные .onion сайты (требуют Tor)
- Другие найденные ресурсы (могут требовать Tor)

**Почему нужен Tor?**
- .onion сайты доступны ТОЛЬКО через Tor
- Без Tor невозможно открыть .onion адреса
- Tor обеспечивает анонимность при доступе к dark web

**Процесс:**
```
1. Найдена ссылка: http://example.onion/page1
2. Открываем через Tor прокси
3. Извлекаем текст со страницы
4. Анализируем содержимое
```

## 🎯 Почему так сделано:

### 1. **Оптимизация скорости:**
- Clearnet поисковые системы работают быстрее без Tor
- Tor замедляет запросы в 3-10 раз
- Поиск без Tor = быстрее результаты

### 2. **Обход блокировок:**
- Некоторые clearnet сайты блокируют запросы через Tor
- Ahmia возвращает 403 Forbidden при запросах через Tor
- Без Tor = нет блокировок

### 3. **Необходимость Tor для .onion:**
- .onion сайты доступны ТОЛЬКО через Tor
- Без Tor невозможно открыть .onion адреса
- Tor обязателен для скрапинга .onion сайтов

## 💡 Аналогия:

**Представьте библиотеку:**

1. **Поиск книг (БЕЗ маски):**
   - Вы идете в обычную библиотеку (clearnet)
   - Ищете книги в каталоге (поисковые системы)
   - Получаете список книг (результаты поиска)
   - Маска не нужна, вы просто ищете информацию

2. **Чтение книг (С маской):**
   - Вы нашли книгу в специальном отделе (.onion сайт)
   - Чтобы прочитать её, нужна маска (Tor)
   - Без маски вы не можете войти в отдел
   - Маска нужна для анонимности и доступа

## 🔧 Технические детали:

### В коде:

#### search.py - Поиск (БЕЗ Tor для clearnet):
```python
# Для clearnet сайтов используем запросы без Tor
clearnet_engines = ['ahmia', 'onionland', 'duckduckgo', 'startpage']
use_tor = engine not in clearnet_engines

if use_tor:
    response = self._make_request(search_url, is_first=is_first)  # С Tor
else:
    # Clearnet запросы без Tor
    response = requests.get(search_url, headers=self.headers, timeout=self.timeout)
```

#### scrape.py - Скрапинг (С Tor):
```python
def __init__(self, use_tor: bool = True):
    self.use_tor = use_tor
    self.proxy = {
        'http': Config.TOR_PROXY,   # Используем Tor прокси
        'https': Config.TOR_PROXY
    } if use_tor else None

# При скрапинге .onion сайтов используется Tor
response = requests.get(url, proxies=self.proxy, ...)  # Через Tor!
```

## 📋 Итого:

### Tor НЕ используется для:
- ❌ Поиска в clearnet поисковых системах (Ahmia, DuckDuckGo и т.д.)
- ❌ Доступа к обычным сайтам

### Tor используется для:
- ✅ Скрапинга найденных .onion сайтов
- ✅ Доступа к dark web ресурсам
- ✅ Обеспечения анонимности при работе с dark web

## 🎯 Вывод:

**Tor нужен не для поиска, а для доступа к найденным .onion сайтам!**

1. **Поиск** → Без Tor (быстрее, нет блокировок)
2. **Скрапинг** → С Tor (обязательно для .onion сайтов)

Это оптимальная стратегия:
- Быстрый поиск без Tor
- Анонимный доступ к dark web через Tor
