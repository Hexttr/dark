## 📝 Как протестировать:

1. Откройте приложение: http://127.0.0.1:8501
2. Введите запрос: `password leak database 2024`
3. Установите потоки: 10-12
4. Нажмите "Запустить расследование"
5. Должны найтись результаты в течение 2-5 минут

## ⚠️ Если нет результатов:

1. **Проверьте Tor:** `python check_tor.py`
2. **Проверьте Ollama:** Убедитесь, что модель загружена
3. **Попробуйте другой запрос:** `data breach database dump`
4. **Уменьшите потоки:** Попробуйте 5-8 потоков
5. **Подождите:** Tor может быть медленным при первом подключении
