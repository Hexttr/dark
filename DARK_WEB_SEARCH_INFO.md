# 🌐 Поиск в Dark Web - Как это работает

## ✅ Да, приложение УЖЕ может искать в даркнете!

### Как это работает:

1. **Ollama (LLM)** - используется для:
   - Генерации оптимизированных поисковых запросов
   - Фильтрации результатов
   - Создания отчетов
   - **НЕ используется для самого поиска**

2. **Поисковые системы Dark Web** - используются для реального поиска:
   - **Ahmia** (clearnet) - https://ahmia.fi
   - **Not Evil** (.onion) - работает через Tor
   - **Candle** (.onion) - работает через Tor
   - **Torch** (.onion) - работает через Tor
   - **Onionland** (clearnet) - дополнительная система
   - **Haystack** (.onion) - дополнительная система

3. **Tor** - обеспечивает анонимный доступ к .onion сайтам

## 🔍 Текущая конфигурация поисковых систем:

Приложение уже настроено и готово к работе! Все поисковые системы подключены через Tor.

## 🚀 Как использовать:

1. Откройте приложение: http://127.0.0.1:8501
2. Введите один из запросов выше
3. Нажмите "Запустить расследование"
4. Приложение автоматически:
   - Сгенерирует оптимизированные запросы
   - Поищет во всех 6 поисковых системах
   - Отфильтрует результаты
   - Создаст отчет

## 🔧 Проверка работы:

Перед использованием убедитесь:
- ✅ Tor запущен и доступен на порту 9050
