# 🏗️ Архитектура приложения Robin

## 📐 Общая структура

```
robin/
├── main.py              # Точка входа, CLI интерфейс
├── config.py            # Конфигурация и настройки
├── llm.py               # Работа с Ollama LLM
├── llm_utils.py         # Утилиты для LLM (промпты, форматирование)
├── search.py            # Поиск в dark web через Tor
├── scrape.py            # Скрапинг результатов поиска
├── ui.py                # Веб-интерфейс Streamlit
├── requirements.txt     # Зависимости Python
├── .env.example         # Пример конфигурации
└── README.md            # Документация
```

## 🔄 Поток данных

```
User Query
    ↓
[main.py] - Парсинг аргументов CLI
    ↓
[llm_utils.py] - Генерация оптимизированных поисковых запросов через Ollama
    ↓
[search.py] - Поиск через Tor в dark web поисковых системах
    ↓
[scrape.py] - Параллельный скрапинг найденных URL (многопоточность)
    ↓
[llm.py] - Фильтрация и анализ результатов через Ollama
    ↓
[llm_utils.py] - Генерация итогового отчета
    ↓
[main.py] - Вывод результата / сохранение в файл
```

## 🧩 Компоненты

### 1. **config.py** - Конфигурация
- Загрузка переменных окружения (.env)
- Настройки Tor (прокси, порты)
- Настройки Ollama (URL, модель по умолчанию)
- Параметры поисковых систем

### 2. **llm.py** - Работа с Ollama
- Класс `OllamaClient` для взаимодействия с Ollama API
- Методы:
  - `generate_queries()` - генерация поисковых запросов
  - `filter_results()` - фильтрация результатов
  - `generate_summary()` - создание итогового отчета

### 3. **llm_utils.py** - Утилиты LLM
- Промпты для разных задач
- Форматирование ответов
- Парсинг JSON ответов от LLM

### 4. **search.py** - Поиск в Dark Web
- Класс `DarkWebSearcher`
- Поддержка нескольких поисковых систем:
  - Ahmia
  - Not Evil
  - Candle
  - Torch
- Работа через Tor SOCKS5 прокси
- Обработка ошибок и таймаутов

### 5. **scrape.py** - Скрапинг
- Класс `ContentScraper`
- Многопоточный скрапинг URL
- Извлечение текста из HTML
- Обработка ошибок и ретраи

### 6. **main.py** - CLI интерфейс
- Парсинг аргументов (argparse)
- Координация всех компонентов
- Вывод результатов
- Сохранение в файл

### 7. **ui.py** - Веб-интерфейс
- Streamlit приложение
- Форма ввода запроса
- Выбор модели Ollama
- Отображение результатов
- Скачивание отчетов

## 🔧 Технологии

- **Python 3.10+**
- **Ollama** - локальный LLM (llama3.1, mistral, и др.)
- **requests** - HTTP запросы
- **requests[socks]** - поддержка SOCKS5 для Tor
- **beautifulsoup4** - парсинг HTML
- **streamlit** - веб-интерфейс
- **python-dotenv** - загрузка .env
- **concurrent.futures** - многопоточность

## 🔐 Безопасность

- Все запросы через Tor
- Локальная обработка данных (Ollama)
- Нет отправки данных в облачные API
- Изоляция через виртуальное окружение

## 🚀 Преимущества архитектуры

1. **Модульность** - каждый компонент независим
2. **Расширяемость** - легко добавить новые поисковые системы
3. **Приватность** - все локально, без облачных API
4. **Производительность** - многопоточный скрапинг
5. **Гибкость** - CLI и Web UI режимы
