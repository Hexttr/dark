# 🔍 Что такое скрапинг и что скрапит наше приложение

## 📖 Что такое скрапинг (Web Scraping)?

**Скрапинг (Web Scraping)** — это автоматическое извлечение данных с веб-страниц.

### Простыми словами:
- Вы открываете веб-страницу в браузере и видите текст, картинки, ссылки
- Скрапинг — это когда программа автоматически открывает страницу и извлекает из неё текст/данные
- Вместо того чтобы читать страницу вручную, программа делает это автоматически

### Пример:
```
Человек: Открывает страницу → Читает текст → Записывает важное
Программа: Открывает страницу → Извлекает текст → Сохраняет в память
```

## 🎯 Что скрапит наше приложение?

### Мы НЕ скрапим результаты поиска!

**Результаты поиска** — это то, что мы получаем от поисковых систем (Ahmia, DuckDuckGo и т.д.). Это уже готовые данные:
- Заголовки результатов
- Ссылки на страницы
- Краткие описания (snippet)

### Мы скрапим СОДЕРЖИМОЕ найденных страниц!

**Что происходит:**

1. **Поиск** → Находим ссылки на .onion сайты и другие страницы
   ```
   Найдено: http://example.onion/page1
   ```

2. **Скрапинг** → Открываем каждую найденную ссылку и извлекаем текст со страницы
   ```
   Открываем: http://example.onion/page1
   Извлекаем: весь текст со страницы (до 10000 символов)
   ```

3. **Анализ** → Анализируем извлеченный текст на наличие упоминаний домена
   ```
   Ищем в тексте: "tcell.tj", "T-Mobile", "утечка данных" и т.д.
   ```

## 🔄 Процесс работы приложения:

### Шаг 1: Поиск (НЕ скрапинг)
```
Поисковая система → Находит ссылки → Возвращает результаты
Результат: список ссылок с заголовками
```

### Шаг 2: Фильтрация (НЕ скрапинг)
```
LLM анализирует результаты → Отбирает релевантные
Результат: отфильтрованный список ссылок
```

### Шаг 3: Скрапинг (ДА, это скрапинг!)
```
Для каждой ссылки:
  1. Открываем страницу через Tor
  2. Извлекаем HTML код
  3. Парсим HTML и извлекаем текст
  4. Сохраняем текст для анализа
Результат: текст со страниц (до 10000 символов на страницу)
```

### Шаг 4: Анализ скрапленного контента
```
LLM анализирует извлеченный текст → Ищет упоминания домена
Результат: отчет с анализом найденной информации
```

## 💡 Зачем нужен скрапинг?

### Без скрапинга:
```
Найдено: http://example.onion/page1
Что мы знаем: только заголовок и краткое описание из поисковой системы
Проблема: не знаем, что реально написано на странице
```

### Со скрапингом:
```
Найдено: http://example.onion/page1
Скрапим: извлекаем весь текст со страницы
Результат: знаем полное содержимое страницы
Анализ: можем найти упоминания "tcell.tj" в тексте
```

## ⚠️ Важно понимать:

1. **Скрапинг — это не поиск**
   - Поиск находит ссылки
   - Скрапинг извлекает содержимое по ссылкам

2. **Скрапинг может быть медленным**
   - Каждая страница открывается отдельно
   - .onion сайты работают медленно через Tor
   - Может занимать 10-30 секунд на страницу

3. **Скрапинг может не сработать**
   - Страница может быть недоступна
   - Может быть таймаут
   - Страница может не содержать текста
