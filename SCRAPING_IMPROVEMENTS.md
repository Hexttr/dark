# 🔧 Улучшения скрапинга и фильтрации

## ✅ Что исправлено:

### 1. **Улучшена фильтрация результатов** ✅

**Проблема:** При поиске "tcell.tj" находились результаты про "T-mobile" (нерелевантные)

**Решение:**
- Добавлена строгая проверка соответствия домена/компании
- LLM теперь получает специальные инструкции для отклонения результатов о других компаниях
- Улучшен промпт фильтрации с акцентом на точное соответствие домена

**Как работает:**
- Если запрос о конкретном домене (например: "tcell.tj"), система:
  - ✅ Принимает только результаты, которые упоминают "tcell.tj"
  - ❌ Отклоняет результаты о других компаниях (T-mobile, T-Mobile, tmobile и т.д.)
  - Оценивает релевантность строже (0.7+ только для точных совпадений)

### 2. **Улучшен скрапинг контента** ✅

**Проблема:** Текст со страниц не извлекался

**Решения:**

#### a) Увеличен таймаут для .onion сайтов
- Обычные сайты: 15 секунд (по умолчанию)
- .onion сайты: 30 секунд (удвоенный таймаут)
- Причина: .onion сайты работают медленнее через Tor

#### b) Улучшено извлечение текста
- **Основной метод:** Ищет `<article>`, `<main>`, или `<div class="content">` сначала
- **Альтернативный метод:** Если основной не работает, использует регулярные выражения
- **Увеличена длина:** С 5000 до 10000 символов на страницу

#### c) Улучшено логирование
- Показывает статус каждого запроса
- Показывает размер извлеченного текста
- Показывает причины ошибок (таймаут, HTTP ошибки и т.д.)
- Показывает статистику: успешно/провалено

#### d) Альтернативный метод извлечения
- Если основной метод не извлекает текст, используется альтернативный
- Использует регулярные выражения для удаления HTML тегов
- Декодирует HTML entities
