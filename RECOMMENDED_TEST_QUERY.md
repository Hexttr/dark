# 🧪 Рекомендуемый тестовый запрос

## ✅ Гарантированно найдет результаты:

### **Запрос для тестирования:**
```
password leak database 2024
```

## 🎯 Почему этот запрос работает:

1. **Очень общий** - точно найдет результаты в dark web
2. **Популярная тема** - много упоминаний в dark web
3. **Не требует специфики** - работает для любого домена/компании
4. **Быстро выполняется** - много результатов

## 📝 Как использовать:

### Вариант 1: Через веб-интерфейс (рекомендуется)
1. Откройте: http://127.0.0.1:8501
2. Введите запрос: `password leak database 2024`
3. Установите потоки: **10-12**
4. Нажмите "Запустить расследование"
5. Подождите 2-5 минут

### Вариант 2: Через CLI
```bash
python main.py cli --query "password leak database 2024" --threads 10
```

## ⚠️ Если нет результатов:

1. **Проверьте Tor:**
   ```bash
   python check_tor.py
   ```
   Должно показать: ✅ Tor готов к работе!

2. **Проверьте Ollama:**
   - Убедитесь, что Ollama запущен
   - Проверьте модель: `ollama list`

3. **Попробуйте:**
   - Уменьшить потоки до 5-8
   - Подождать дольше (Tor может быть медленным)
   - Попробовать другой запрос

4. **Проверьте поисковые системы:**
   - Ahmia может быть недоступна
   - .onion сайты могут быть медленными
   - Попробуйте подождать 5-10 минут

- ✅ Отфильтровано X релевантных результатов
