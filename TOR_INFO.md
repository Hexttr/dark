# ⏱️ Информация о скорости Tor

## Почему Tor медленный?

Tor может быть медленным по нескольким причинам:

### 1. **Первое подключение (30-120 секунд)**
При первом запуске Tor нужно:
- Установить соединение с узлами сети
- Построить цепочку из 3 узлов (guard → middle → exit)
- Загрузить список узлов (consensus)
- Установить зашифрованные соединения

**Это нормально!** После первого подключения последующие запросы будут быстрее.

### 2. **Маршрутизация через несколько узлов**
Каждый запрос проходит через 3 случайных узла в разных странах, что увеличивает задержку.

### 3. **Шифрование**
Многослойное шифрование добавляет задержку, но обеспечивает анонимность.

## ⏱️ Типичные времена подключения

- **Первое подключение:** 30-120 секунд
- **Последующие запросы:** 5-30 секунд
- **Быстрые запросы (после прогрева):** 3-10 секунд

## 🚀 Как ускорить?

### 1. **Дождитесь прогрева Tor**
После первого запуска Tor Browser подождите 1-2 минуты перед использованием.

### 2. **Используйте быстрые узлы**
Tor автоматически выбирает быстрые узлы, но это может занять время.

### 3. **Увеличьте таймауты в .env**
```env
TOR_TIMEOUT=60
TOR_CONNECTION_TIMEOUT=120
```

### 4. **Проверьте соединение заранее**
Запустите утилиту проверки:
```bash
python check_tor.py
```

## 🔍 Проверка работы Tor

### Быстрая проверка
```bash
# Проверить, что Tor слушает на порту 9050
netstat -an | findstr 9050  # Windows
netstat -an | grep 9050     # Linux/Mac
```

### Проверка через браузер
1. Откройте Tor Browser
2. Перейдите на https://check.torproject.org
3. Должно показать "Congratulations. This browser is configured to use Tor."

### Проверка через утилиту
```bash
python check_tor.py
```

## 💡 Советы

1. **Не прерывайте первое подключение** - дайте Tor время установить соединение
2. **Используйте Tor Browser** - он автоматически настраивает все параметры
3. **Проверьте интернет-соединение** - медленный интернет = медленный Tor
4. **Закройте другие приложения** - они могут использовать Tor и замедлять его

## ⚙️ Настройки в приложении

В файле `.env` можно настроить:

```env
# Таймаут для обычных запросов (секунды)
TOR_TIMEOUT=60

# Таймаут для первого подключения (секунды)
TOR_CONNECTION_TIMEOUT=120
```

## 🐌 Если Tor очень медленный

1. **Проверьте интернет-соединение**
2. **Перезапустите Tor Browser**
3. **Проверьте, не блокирует ли файрвол Tor**
4. **Попробуйте в другое время** - сеть Tor может быть перегружена

## ✅ Нормальное поведение

- Первый запрос: **30-120 секунд** ⏱️
- Второй запрос: **10-30 секунд** ⏱️
- Последующие: **5-15 секунд** ⏱️

**Это нормально!** Tor жертвует скоростью ради анонимности и безопасности.
