# 🔍 Анализ поиска tcell.tj

## 📊 Что находит приложение:

### Текущая логика поиска:

1. **Ahmia** ищет .onion сайты по ключевым словам
2. **Парсер** извлекает ссылки на .onion сайты
3. **LLM фильтрует** результаты по релевантности
4. **Генерируется отчет** с найденными ссылками

### ⚠️ Важное понимание:

**Приложение НЕ ищет напрямую упоминания домена tcell.tj**

Вместо этого оно:
- Ищет .onion сайты, которые могут содержать информацию по запросу
- Находит ссылки на dark web ресурсы
- Фильтрует их по релевантности

### 🎯 Что это означает для tcell.tj:

Если приложение нашло результаты, это может быть:

1. **.onion сайты**, которые упоминают tcell.tj в контексте:
   - Утечек данных
   - Продажи данных
   - Обсуждений на форумах
   - Торговых площадок

2. **НЕ прямые упоминания** домена в результатах поиска Ahmia

3. **Требуется скрапинг** найденных .onion сайтов для проверки содержимого

## 🔍 Как проверить, что именно найдено:

### Вариант 1: Проверить отчет
- Посмотрите на найденные URL (.onion ссылки)
- Проверьте snippet (краткое описание)
- Оцените релевантность
